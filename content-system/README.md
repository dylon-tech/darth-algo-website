# Darth Algo AI Content System

Use this folder as the operating system for promoting Darth Algo across TikTok, Instagram Reels, YouTube Shorts, X, email, and blog posts.

## Weekly Workflow

1. Collect raw material:
   - Indicator screenshots
   - Winning and losing trade examples
   - Customer questions
   - Product updates
   - Short screen recordings from TradingView

2. Generate content:
   - Use `ai-agent-prompts.md` to turn raw material into scripts, captions, blogs, and emails.
   - Use `video-script-bank.md` when you need ready-to-record short-form ideas.
   - Use `content-calendar.md` to decide what to post each day.

3. Review before publishing:
   - Run every post through the Compliance Review Agent prompt.
   - Remove any language that sounds like guaranteed profit, financial advice, or certain future performance.
   - Make sure a disclaimer is present when performance, trades, or backtests are mentioned.

4. Publish and track:
   - Save each post idea, platform, date, hook, CTA, and result.
   - Track views, clicks, email signups, free trials, paid subscriptions, and lifetime purchases.
   - Double down on hooks that create qualified clicks to the website.

## Agent Roles

- Content Strategist Agent: plans weekly themes and campaigns.
- Chart Breakdown Agent: explains indicator screenshots in plain trader language.
- Short-Form Script Agent: writes TikTok, Reels, and Shorts scripts.
- Caption Agent: writes captions, hashtags, and CTAs.
- Blog Agent: writes SEO-friendly educational posts.
- Newsletter Agent: writes emails for leads and existing customers.
- Compliance Review Agent: checks for risky claims before publishing.
- Repurposing Agent: turns one winning idea into posts across several platforms.

## Best Starting Point

Start with:

1. `brand-rules.md`
2. `ai-agent-prompts.md`
3. `video-script-bank.md`

Then use `content-calendar.md` to stay consistent for the first 30 days.
