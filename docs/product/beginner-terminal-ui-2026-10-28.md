# Beginner-first Darth Algo Terminal

## Core promise
A clear practice-first workflow: **Choose market → Review strategy → Start paper trading → See results**. Avoid dense technical menus and misleading claims about profits.

## First screen
- Market: Gold / Nasdaq / S&P 500
- Strategy: Auto (recommended default), Reversal, Trend
- Account mode: Paper (default)
- One main action: Start practice
- Compact status: Waiting / Setup detected / Paper trade open / Paused
- Show explanation for signals on demand, not permanently on chart

## Secondary screens
- Performance: sample size, net P&L after fees, drawdown, expectancy, profit factor, dates and simulated label
- Activity: trade log and alerts
- Settings: risk limit, position sizing, session; advanced settings collapsed

## Safety and testing
- Paper mode before any broker integration
- Non-repainting signal tests and untouched out-of-sample comparisons
- Daily loss cap, max exposure, emergency stop, idempotent alert handling
- Never imply an automatic strategy is profitable without verified evidence
- Mobile-first design, accessible contrast and tap targets

## Reference approach
Learn from the simplicity of modern trading interfaces without copying protected layouts, brand elements, or proprietary implementation. Validate against real users and device sizes.

## Implementation order
1. Wireframe and usability test; 2. backtest API and paper simulation; 3. dashboard; 4. onboarding; 5. production hardening; 6. separately approved broker integration.
